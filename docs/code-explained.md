# Разбор кода: что делает каждая строка и почему так

Документ для подготовки к защите. По каждому модулю: назначение, разбор
кода построчно, принятые решения с альтернативами и вопросы, которые
логично задать по этому месту.

Готово: `client.py`.
В работе: `parsers.py`, `db.py`, `cli.py`, аналитика, бот.

# 1. `src/tender_radar/client.py` — HTTP-клиент

## Зачем нужен модуль

Единственное место в проекте, которое ходит в интернет. Все обращения к
ЕИС проходят через него, поэтому правила поведения — пауза между запросами,
повторы при сбоях, реакция на блокировку — заданы в одном месте, а не
размазаны по коду. Если завтра решим сменить режим нагрузки, правим один файл.

## Строки 1–6: строка документации модуля

```python
"""HTTP client for zakupki.gov.ru (ЕИС) public HTML pages.
...
"""
```

Docstring — строка документации. Стоит первой в файле, поэтому Python
сохраняет ее в атрибут `__doc__` модуля, и она видна через `help()`.
Здесь зафиксировано главное про источник: сайт отдает обычный HTTPS,
сертификат выпущен российским удостоверяющим центром, которого нет в
хранилище macOS, поэтому проверка сертификата намеренно отключена.

**Зачем это в коде, а не в голове:** через два месяца строка
`self.session.verify = False` выглядит как небрежность. Комментарий
объясняет, что это осознанное решение и почему оно принято.

## Строка 8: импорт из будущего

```python
from __future__ import annotations
```

Позволяет писать аннотации типов вроде `Path | None` (это или объект Path,
или ничего) в Python 3.9, где такой синтаксис иначе вызвал бы ошибку.
На твоем Mac стоит именно 3.9. Без этой строки файл не запустится.

## Строки 10–15: импорты

```python
import logging
import time
from pathlib import Path

import requests
import urllib3
```

`logging` — журналирование: вместо `print` сообщения идут в лог с меткой
времени и уровнем важности. `time` — паузы между запросами. `Path` — работа
с путями к файлам. `requests` — библиотека HTTP-запросов, `urllib3` — то,
на чем `requests` работает внутри.

Пустая строка разделяет стандартную библиотеку Python и внешние пакеты —
это соглашение PEP 8, по нему сразу видно, что нужно устанавливать через pip.

## Строка 17: отключение предупреждений

```python
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)
```

Раз проверка сертификата выключена, `urllib3` на каждый запрос печатает
предупреждение. За сутки это полторы сотни одинаковых строк в логе, среди
которых теряется полезное. Строка их глушит.

**Решение и альтернатива:** правильнее было бы добавить российский корневой
сертификат в доверенные и включить проверку обратно. Это делается, но
требует настройки на каждой машине, где запускается проект. Для учебной
работы выбран простой путь, и он явно задокументирован. На защите это
корректный ответ: знаем о компромиссе, понимаем последствия — клиент не
проверяет подлинность сервера.

## Строка 19: логгер модуля

```python
log = logging.getLogger(__name__)
```

`__name__` — служебная переменная Python с именем модуля, здесь
`tender_radar.client`. Логгер с таким именем помечает каждое сообщение
источником, и в общем логе видно, какой модуль что написал.

## Строки 21–25: константы

```python
BASE_URL = "https://zakupki.gov.ru"
USER_AGENT = ("Mozilla/5.0 ... Chrome/128.0 Safari/537.36")
```

Заглавные буквы — соглашение: значение не меняется во время работы.

`User-Agent` — заголовок, которым браузер представляется сайту. Мы
отправляем строку обычного Chrome на macOS.

**Здесь будет вопрос на защите:** «вы маскируетесь под браузер?» Честный
ответ: библиотека `requests` по умолчанию присылает `python-requests/2.x`,
и часть сайтов отдает таким клиентам другую верстку или отказывает. Мы
запрашиваем те же публичные страницы, что и человек в браузере, и в том же
темпе; заголовок нужен, чтобы получить нормальную верстку. При этом когда
ЕИС нас заблокировал, мы не стали менять заголовки, чтобы обойти защиту —
мы снизили нагрузку. Это принципиальная разница, и она видна по истории
коммитов.

## Строки 28–33: собственный класс ошибки

```python
class BlockedError(RuntimeError):
    """ЕИС временно заблокировал IP за автоматический сбор."""
```

Наследуется от `RuntimeError` — то есть это обычное исключение, но со своим
именем. Нужно, чтобы отличать блокировку от прочих сбоев сети.

**Почему отдельный класс:** сетевую ошибку надо повторить, блокировку —
ни в коем случае. Повтор запроса при блокировке продлевает ее и усугубляет
ситуацию. Разные ошибки требуют разного поведения, поэтому они разных типов.

Тело класса — только строка документации. В Python это допустимо: docstring
служит телом, отдельный `pass` не нужен.

## Строки 36–48: конструктор клиента

```python
class EisClient:
    def __init__(self, delay: float = 2.0, retries: int = 3, raw_dir: Path | None = None):
```

`__init__` вызывается при создании объекта. Три параметра со значениями по
умолчанию: пауза между запросами, число попыток, папка для сохранения
сырого HTML.

**Почему параметры, а не жестко зашитые числа:** ежедневный сбор идет с
паузой 5 секунд, а разовая проверка может работать быстрее. Значение
передается при создании клиента, код менять не нужно.

```python
        self._last_request = 0.0
```

Время последнего запроса. Подчеркивание в начале имени — соглашение:
поле внутреннее, снаружи его трогать не следует.

```python
        self.session = requests.Session()
```

Сессия вместо отдельных вызовов `requests.get`. Сессия переиспользует
TCP-соединение между запросами и хранит cookies. Это и быстрее, и ближе
к поведению браузера: обычный посетитель тоже не устанавливает новое
соединение на каждую страницу.

```python
        self.session.headers.update({...})
```

Заголовки задаются один раз на всю сессию, а не повторяются в каждом
запросе. `Accept-Language: ru-RU` — просим русскую версию страницы,
`Accept: text/html` — ожидаем HTML.

```python
        self.session.verify = False
```

Та самая отключенная проверка сертификата, объясненная в начале файла.

## Строки 50–71: метод get — главный метод модуля

```python
    def get(self, path: str, params: dict | None = None, save_as: str | None = None) -> str:
```

Принимает путь на сайте, параметры запроса и, по желанию, имя файла для
сохранения. Возвращает HTML-текст страницы. Аннотация `-> str` говорит,
что на выходе строка.

```python
        url = path if path.startswith("http") else BASE_URL + path
```

Тернарное выражение: если путь уже полный адрес — берем как есть, иначе
приписываем спереди адрес сайта. Позволяет вызывать метод и коротким путем
`/epz/contract/...`, и полной ссылкой.

```python
        for attempt in range(1, self.retries + 1):
```

Цикл попыток. `range(1, 4)` дает 1, 2, 3 — правая граница не включается,
поэтому `+ 1`. Нумерация с единицы, а не с нуля, чтобы в логе читалось
«попытка 1 из 3».

```python
            self._throttle()
```

Пауза перед каждым запросом. Разобран ниже.

```python
            try:
                resp = self.session.get(url, params=params, timeout=60)
```

`timeout=60` обязателен. Без него запрос к зависшему серверу может висеть
бесконечно, и ежедневный сбор остановится навсегда, не выдав ошибки.

```python
                if resp.status_code == 403 or "подозрительная активность" in resp.text:
                    raise BlockedError(...)
```

Два признака блокировки. Код 403 — прямой отказ. Но ЕИС иногда отдает
страницу с кодом 200, а внутри текст про подозрительную активность —
формально успех, фактически отказ. Поэтому проверяем и тело ответа.

**Откуда взялась вторая проверка:** из реального случая 22 сентября.
Сначала сайт отдавал пустую выдачу с кодом 200, и код принимал это за
«контрактов нет». Три дня данных потеряно, пока причина не выяснилась.
Хороший пример для защиты: код научился распознавать отказ, замаскированный
под успех.

```python
                if resp.status_code == 200 and len(resp.text) > 1000:
```

Успехом считаем только содержательный ответ. Проверка длины отсекает
страницы-заглушки: настоящая страница ЕИС весит сотни килобайт, а короткий
ответ — почти наверняка ошибка.

```python
                    if self.raw_dir and save_as:
                        self.raw_dir.mkdir(parents=True, exist_ok=True)
                        (self.raw_dir / save_as).write_text(resp.text, encoding="utf-8")
```

Сохранение сырого HTML, если папка задана. `parents=True` создает
промежуточные папки, `exist_ok=True` не ругается, если папка уже есть.

**Зачем хранить сырье:** если завтра выяснится, что парсер неверно читал
какое-то поле, страницы можно разобрать заново, не обращаясь к сайту
повторно. Плюс из них сделаны тесты. Для научной работы это еще и
воспроизводимость: исходные данные сохранены.

```python
                    return resp.text
```

Успех — выходим из метода, цикл попыток прерывается.

```python
                log.warning("GET %s -> %s (%d bytes), attempt %d", ...)
```

Сюда попадаем, если ответ пришел, но не подошел. Пишем в лог и идем на
следующую попытку. Аргументы передаются в логгер отдельно, а не
склеиваются в строку заранее — так строка собирается только если
сообщение действительно будет записано.

```python
            except BlockedError:
                raise
```

Блокировку пропускаем наружу без повторов. Без этих двух строк ее поймал
бы обработчик ниже и честно попробовал еще раз — ровно то, чего делать
нельзя.

```python
            except requests.RequestException as exc:
                log.warning("GET %s failed: %s, attempt %d", url, exc, attempt)
```

Ловим сетевые сбои: обрыв соединения, таймаут, ошибка DNS. Ловим именно
`requests.RequestException`, а не все подряд: ошибка в собственном коде
должна падать громко, а не прятаться в лог.

```python
            time.sleep(self.delay * attempt * 2)
```

Пауза перед следующей попыткой, растущая с номером попытки: при паузе
5 секунд это 10, 20, 30 секунд. Если сайт перегружен, повторный штурм
в том же темпе делает хуже.

```python
        raise RuntimeError(f"failed to fetch {url} after {self.retries} attempts")
```

Все попытки исчерпаны — падаем с понятным сообщением. Молча вернуть пустую
строку было бы хуже: ошибка всплыла бы позже и в другом месте.

## Строки 73–77: троттлинг

```python
    def _throttle(self) -> None:
        wait = self.delay - (time.monotonic() - self._last_request)
        if wait > 0:
            time.sleep(wait)
        self._last_request = time.monotonic()
```

Гарантирует минимальный промежуток между запросами. Считаем, сколько
прошло с прошлого раза, и досыпаем недостающее. Если обработка страницы
заняла 3 секунды из требуемых 5, ждем только 2.

`time.monotonic()` вместо `time.time()` — монотонные часы, которые не
перескакивают при переводе системного времени или синхронизации по сети.
Для измерения интервалов нужны именно они.

**Почему пауза, а не запросы подряд:** это ограничение нагрузки на
источник. После блокировки 22 сентября пауза увеличена с 2 до 5 секунд,
а суточный объем снижен с 250 карточек до 150.

## Вопросы по этому модулю и ответы

**Почему `requests`, а не `urllib` из стандартной библиотеки?**
`requests` дает сессии с переиспользованием соединений, автоматическую
обработку редиректов и кодировок. На `urllib` это писалось бы вручную.

**Почему отключена проверка сертификата — это ведь небезопасно?**
Да, клиент не проверяет подлинность сервера. Сертификат ЕИС выпущен
российским УЦ, отсутствующим в хранилище macOS. Правильное решение —
добавить корневой сертификат в доверенные; в учебной работе выбран
простой путь, компромисс зафиксирован в документации.

**Зачем подменять User-Agent?**
Не подменять, а представляться так, чтобы получить обычную верстку:
`requests` по умолчанию шлет `python-requests`, и часть сайтов отдает
таким клиентам другой ответ. Запрашиваем те же публичные страницы, что и
человек в браузере. Обходить блокировку сменой заголовков мы не стали —
вместо этого снизили нагрузку.

**Что будет, если ЕИС заблокирует навсегда?**
Сбор остановится с понятной ошибкой, уже накопленные данные останутся.
Запасные пути: снизить темп еще, перейти на официальный сервис отдачи
информации по токену, либо запускать сбор с другой машины.

**Почему три попытки, а не одна или десять?**
Одна не переживет случайный сетевой сбой, которые у ЕИС регулярны.
Десять при реальной недоступности сайта превращаются в долбежку. Три
попытки с растущей паузой покрывают временные сбои и не создают нагрузки.
